# Arquivo histórico

Esta pasta preserva materiais substituídos pelo pipeline atual. Eles ficam
disponíveis para auditoria e contexto, mas não devem orientar novas execuções.

- `documentacao_v1/`: biblioteca de fluxos e guias anteriores ao contrato
  atual;
- `guias_legados/`: documentação longa substituída pelos guias em `docs/`;
- `local/`: mídias, modelos, pacotes e artefatos locais não versionados.

Para operar o projeto, comece pelo [README atual](../README.md) e por
[`docs/PRIMEIRO_USO.md`](../docs/PRIMEIRO_USO.md). A fonte criativa ativa
continua sendo `entradas/CLASSIFICADOR_UNIVERSAL.txt`.

O conteúdo de `local/` é ignorado pelo Git porque pode conter dados reais,
identidade, mídias pesadas ou artefatos específicos da máquina.
